# We Take Care

ROLLE

Du bist ein erfahrener Senior Full-Stack-Entwickler, UX/UI-Designer, Product Designer und Softwarearchitekt.

Deine Aufgabe ist es, eine hochwertige, moderne und professionell wirkende Website inklusive funktionierendem Frontend und Backend für mein Unternehmen zu konzipieren und zu programmieren.

Die Website soll NICHT wie eine typische Handwerker-Vermittlungsplattform, ein anonymes Beschwerdeportal oder eine klassische Kanzlei aussehen.

Sie soll persönlich, vertrauenswürdig, modern und menschlich wirken.

Der zentrale Gedanke der Marke lautet:

„Du musst dich nicht darum kümmern. Wir kümmern uns.“

Das Unternehmen hilft Privatkunden dabei, Kommunikationsprobleme mit Handwerkern und anderen Dienstleistern zu lösen.



1. GESCHÄFTSIDEE

Mein Unternehmen übernimmt für Kunden die Kommunikation mit Dienstleistern, wenn es Probleme gibt.

Typische Situationen:

Ein Handwerker meldet sich nicht mehr.

Ein Dienstleister ist telefonisch nicht erreichbar.

Ein vereinbarter Termin wurde nicht eingehalten.

Ein Auftrag verzögert sich.

Eine Arbeit wurde nicht fertiggestellt.

Der Kunde bekommt keine Rückmeldung.

Ein Dienstleister reagiert nicht auf Nachrichten oder E-Mails.

Der Kunde weiß nicht, wie er den Dienstleister erreichen soll.

Der Kunde hat Schwierigkeiten, eine verbindliche Aussage oder einen Termin zu bekommen.

Zwischen Kunde und Dienstleister herrscht eine festgefahrene Kommunikation.

Der Kunde möchte nicht mehr selbst hinterhertelefonieren.

Wichtig:

Das Unternehmen soll zunächst primär als Kommunikations- und Problemlösungsdienstleister auftreten.

Es soll NICHT der Eindruck entstehen, dass das Unternehmen automatisch Rechtsberatung anbietet.

Bei rechtlich komplexen Sachverhalten soll später eine entsprechende Weiterleitung an geeignete Fachstellen möglich sein.

5. DAS PERSÖNLICHE GESPRÄCH

Im Gespräch klärt mein Unternehmen gemeinsam mit dem Kunden:

Was genau ist passiert?

Was wurde ursprünglich vereinbart?

Was möchte der Kunde erreichen?

Was ist besonders dringend?

Welche Kontaktversuche gab es?

Welche Informationen fehlen?

Welche Dokumente sind relevant?

Was wäre für den Kunden eine akzeptable Lösung?

Nach dem Gespräch kann mein Unternehmen den Fall übernehmen.

Der Kunde erhält anschließend beispielsweise:

„Wir übernehmen deinen Fall.“

Und:

„Wir werden innerhalb von bis zu 2 Werktagen versuchen, den Dienstleister zu kontaktieren und eine Lösung bzw. verbindliche Vereinbarung zu erreichen.“

Diese Frist soll auf der Website prominent, aber nicht aggressiv kommuniziert werden.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
